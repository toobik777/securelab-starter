# Проєкт повідомлення викладачеві: advanced variant (відмінний рівень, ЛР 6)

**Статус:** відправлення й відповідь **відсутні** (погодження не отримано; пункт у review не позначено PASS).

Тема: розподілений rate limiter на Redis із перевіркою failure mode.
- **Мета:** показати, що лічильник search-limiter спільний для двох екземплярів API (порти 5080 і 5081) і зберігається з TTL.
- **Де працює Redis:** окремий локальний контейнер, порт лише на `127.0.0.1`; `infra/compose.yaml` буде доповнено сервісом `redis` (без публікації назовні).
- **.NET-клієнт:** `StackExchange.Redis` (нова залежність; після додавання — оновлення `packages.lock.json` і повторний dependency audit).
- **Що зберігається:** лише лічильник partition `search:user:<id>` із TTL, що дорівнює вікну limiter; жодних паролів, cookie чи бізнес-даних.
- **Перевірка:** (1) два API-інстанси на різних портах; квота вичерпується сумарно; (2) ізоляція partitions: вичерпана квота alice не блокує bob; (3) TTL: після вікна лічильник скидається; (4) failure mode: Redis зупинено → API лишається доступним (fail-open із записом у журнал) або повертає узгоджений 503 за рішенням викладача.
- **Межі:** не замінює authentication/authorization; без файлового upload.

Прошу погодити тему або вказати рівноцінне розширення до початку реалізації.
