# Початок WEB ЛР5

Вхід: власний перевірений v0.4.0. Розпакуйте ZIP поза Git-проєктом. На чистій гілці lab/5-browser-xss виконайте install.py з номером 05 та абсолютним шляхом у лапках: dry run → п’ять шляхів → --write → Git diff → commit. README містить точну процедуру.

lab-05/files — чотири навчальні файли, які встановить installer. resources — допоміжні готові приклади/каркаси; installer їх у застосунок не копіює. Не запускайте всі приклади разом. resources/copyable/README.md має навігацію; resources/lab05-marker.txt — єдине джерело marker для копіювання.

Методичка PDF/DOCX містить передумови, очікування й діагностику. Повторне встановлення після receipt заборонене; попередні власні виправлення не перезаписуються. Готового safe DOM fix тут немає.
